WHAT THESE RESULTS MEAN

Reproducible, with clear limits.

24 synthetic test cases

16 development and 8 held-out cases across 8 slices. Every case has a labeled expected decision and source IDs. Paraphrases share templates; this is a smoke suite, not an independent generalization benchmark.

Exact checks, visible evidence

Decision correctness, retrieval coverage, citation IDs, output schema, and canary leakage. Citation checks do not establish semantic faithfulness. There is no LLM judge in this version.

Fixture or real model

The bundled report uses deterministic fixtures. Python can evaluate an OpenAI-compatible endpoint separately. No API keys are accepted or stored in this public page.
